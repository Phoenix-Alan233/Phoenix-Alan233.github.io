# C++ 语言

!!! tip "备注"
    - C++ 是由 Bjarne Stroustrup 于 1979 年在 AT&T 贝尔工作室开发的，作为 C 语言的一个扩展。
    - 大二有幸在浙大校园见到了 Bjarne Stroustrup 本人，听了他的讲座！
    - 少用 `#include <bits/stdc++.h>`，用标准库；少用 `using namespace std;`，不要污染整个命名空间；尽可能使用 C++ 的特性，减少 C/C++ 混用。

!!! 参考资料

    - ZJU 2024-2025 春夏，211C0010，面向对象程序设计
        - 主要介绍 C++ 98 和部分 C++ 11 的相关语法，以及面向对象的特性（封装、继承、多态）
