### 数列

我们按值域从小到大 dp，枚举每个数选多少次。设 $dp[i][j][q][s]$ 表示值域 $0,1,\cdots,i-1$ 已经处理完，选了 $j$ 个数，传入第 $i$ 位的进位为 $q$，并且第 $0\sim i-1$ 位中已经有 $s$ 个 $1$ 时，所有方案的权值和。

接下来枚举选 $t$ 个 $i$，其中 $0\le t\le n-j$。这一位总共有 $q+t$，于是：

- 当前位为 $(q+t)\bmod 2$，把它加到 $s$ 上；

- 传给下一位的进位为 $\lfloor(q+t)/2\rfloor$；

- 新选的这些数贡献 $v_i^t$，并且要从剩下的 $n-j$ 个位置里选出 $t$ 个来放，所以还要乘上 $\binom{n-j}{t}$。

因此转移为：

$$
dp\left[i+1\right]\left[j+t\right]\left[\left\lfloor\frac{q+t}{2}\right\rfloor\right]\left[s+(q+t)\bmod 2\right]
\mathrel{+}=dp[i][j][q][s]\binom{n-j}{t}v_i^t.
$$

初始化 $dp[0][0][0][0]=1$，其他状态为 $0$，枚举 $i=0\sim m$ 依次转移。低位确定以后就不会再变化，所以 $s>k$ 的状态可以直接扔掉。

处理完 $m$ 以后还有一个小细节：进位 $q$ 可能没有清空，它就是剩下那些高位组成的数，因此还要把 $\operatorname{popcount}(q)$ 算进去，不能只判断 $s\le k$。答案就是所有满足 $s+\operatorname{popcount}(q)\le k$ 的 $dp[m+1][n][q][s]$ 之和。

时间复杂度 $O(mn^3k)$，滚动数组可以做到空间复杂度 $O(n^2k+m)$。

### 移球游戏

我们先考虑 $n=2$ 的情形，把两种颜色记成 $0,1$，两根满柱子记成 $A,B$，空柱子记成 $C$。我们希望最后 $A$ 里全是 $1$，$B$ 里全是 $0$。一个自然的想法是，先把 $A$ 里的球按颜色分开，再处理 $B$；问题是其他柱子未必有足够的位置，怎么腾地方呢🤔？

记 $A$ 里有 $s$ 个 $1$，我们可以这样操作：

1. 把 $B$ 顶部的 $s$ 个球移到 $C$。这样 $B$ 空出 $s$ 个位置，$C$ 还剩 $m-s$ 个位置，刚好分别放得下 $A$ 里的 $1$ 和 $0$。

2. 把 $A$ 里的球逐个移出，遇到 $1$ 就移到 $B$，遇到 $0$ 就移到 $C$。现在 $A$ 空了，$B,C$ 都满了。

3. 把 $B$ 里的球全部移到 $A$。这样 $A$ 的底部是 $s$ 个 $1$，上面是原来 $B$ 里的 $m-s$ 个球。

4. 把 $C$ 顶部的 $m-s$ 个 $0$ 移到 $B$。

5. 把 $A$ 顶部的 $m-s$ 个球移到 $C$。这时候就很舒服了：$A$ 里只剩 $s$ 个 $1$，$B$ 里只剩 $m-s$ 个 $0$，而原来 $B$ 里的球全部集中到了 $C$。

6. 把 $C$ 里的球逐个移出，$1$ 移到 $A$，$0$ 移到 $B$。由于两种颜色各有 $m$ 个，所以一定刚好放满，$C$ 也重新变空了。

操作次数为 $s+m+m+(m-s)+(m-s)+m=5m-s\le 5m$，于是我们就得到了一个线性操作次数的做法。

接下来考虑多种颜色。既然两种颜色很好处理，那我们就把颜色分成两类：选一个阈值 $mid$，把 $\le mid$ 的颜色都看成 $1$，$>mid$ 的颜色都看成 $0$，先把两类分开，再分别递归下去。

具体而言，设 $solve(l,r)$ 表示把编号在 $[l,r]$ 内的柱子整理好，并且进入时这些柱子都是满的，里面只有 $[l,r]$ 内的颜色，$n+1$ 号柱子为空。取 $mid=\lfloor(l+r)/2\rfloor$，我们希望左边 $[l,mid]$ 的柱子里全是小颜色，右边 $[mid+1,r]$ 的柱子里全是大颜色。

这里有个小问题：从中拿出两根柱子，里面的 $0,1$ 未必各有 $m$ 个，上面的做法还能用吗？其实前五步完全不受影响。只要两根柱子里总共有至少 $m$ 个 $1$，第六步改成“遇到 $1$ 且 $A$ 没满就移到 $A$，否则移到 $B$”即可。因为一定能给 $A$ 补上 $m-s$ 个 $1$，剩下的 $s$ 个球刚好放进 $B$，所以每一步都放得下。最后 $A$ 全是 $1$，$B$ 可以仍然混着两类球，$C$ 重新变空；如果要收集 $0$，交换两类的角色即可，操作次数仍然至多是 $5m$。

于是我们每次从左边找一根仍然有大颜色的柱子 $i$，从右边找一根仍然有小颜色的柱子 $j$，记这两根柱子中小颜色球的总数为 $t$：

- 如果 $t\ge m$，就用上面的操作把 $i$ 填满小颜色，$i$ 归位。
- 否则，大颜色球有 $2m-t>m$ 个，对称地把 $j$ 填满大颜色，$j$ 归位。

每次至少有一根柱子归位，已经归位的柱子就不用再碰。如果一边全部归位，那么另一边也一定归位，因为小颜色球恰好有 $(mid-l+1)m$ 个，刚好填满左边，大颜色同理。完成这一步后，递归处理 $solve(l,mid)$ 和 $solve(mid+1,r)$，直到 $l=r$，每根柱子就只有一种颜色了。

最后算一下操作次数。一个含 $k$ 根柱子的区间至多配对 $k-1$ 次，因为每次至少归位一根，剩下最后一根时也会自动归位。每层分治中，各个区间的柱子总数不超过 $n$，所以每层至多用 $5nm$ 次操作；分治至多有 $\lceil\log_2 n\rceil$ 层，因此总操作次数不超过

$$
5nm\lceil\log_2 n\rceil\le 5\times 50\times 400\times 6=600000<820000
$$

每层用两个指针分别寻找左右尚未归位的柱子，再逐次模拟移球即可，时间复杂度 $O(nm\log n)$。

### 微信步数

记 $s_{i,j}$ 表示走完前 $i$ 步后第 $j$ 维的位移，$L_{i,j},R_{i,j}$ 分别表示到这时为止，第 $j$ 维出现过的最小、最大位移。一个起点走完前 $i$ 步后仍没有出界，当且仅当它在第 $j$ 维的初始坐标落在

$$
[1-L_{i,j},\ w_j-R_{i,j}]
$$

内。因此走完前 $i$ 步仍在场内的起点数为

$$
\prod_{j=1}^{k}\max(0,w_j-R_{i,j}+L_{i,j}).
$$

计数时，先把所有起点对第 $1$ 步的贡献加进去；之后每走完一步，就把此时仍在场内的起点数加入答案，作为它们下一步的贡献。这样，某个起点出界的那一步也会被计入。第一轮直接扫一遍即可。

记一轮结束后第 $j$ 维的总位移为 $\delta_j$。如果所有 $\delta_j=0$，走完一轮后仍在场内的起点以后会永远重复同一条路线，此时答案为 $-1$；如果第一轮结束时已经没有起点留在场内，答案就是第一轮的贡献。

下面考虑至少有一个 $\delta_j\ne0$ 的情况。第一轮以后，在相同的轮内位置上，每多走一轮，第 $j$ 维经过区间的长度恰好增加 $|\delta_j|$。设第二轮走完第 $i$ 步后，第 $j$ 维还可选择的初始坐标数量为 $b_{i,j}$，那么第 $x+2$ 轮同一位置的数量就是

$$
b_{i,j}-x|\delta_j|.
$$

这里的 $x=0$ 就是第二轮。于是，只要这一整轮结束前还有起点没有出界，这一轮的贡献就是

$$
F(x)=\sum_{i=1}^{n}\prod_{j=1}^{k}
\left(b_{i,j}-x|\delta_j|\right),
$$

它是一个次数不超过 $k$ 的多项式。

扫描第二轮时，顺便求出最早出现某一维可选数量不大于 $0$ 的轮数 $T$。于是 $x=0,1,\ldots,T-1$ 对应完整轮，前 $T$ 个完整轮的总贡献

$$
G(T)=\sum_{x=0}^{T-1}F(x)
$$

是一个次数不超过 $k+1$ 的多项式。计算 $G(0),G(1),\ldots,G(k+1)$，再用拉格朗日插值求出 $G(T)$。最后的第 $T+2$ 轮可能只能走一部分，不能继续套多项式，直接从第一轮结束后的状态开始扫描一遍，并把每一维的可选数量截到 $0$。

总共只扫描常数遍路线。计算插值所需的函数值花费 $O(nk^2)$，空间复杂度为 $O(n+k)$。

### 逛公园

> 给定一张 $n$ 个点、$m$ 条边的有向图，边权非负，可以重复经过点和边。设 $1$ 到 $n$ 的最短路长为 $d$，求长度不超过 $d+K$ 的路线数量，对 $P$ 取模。如果有无穷多条，输出 $-1$。
>
> 多测，$n\le 10^5$，$m\le 2\times 10^5$，$0\le K\le 50$，$0\le w\le 1000$，$1\le P\le 10^9$。保证 $1$ 能到达 $n$。

先跑两遍 Dijkstra，记 $f[u]$ 表示 $1\to u$ 的最短路，$g[u]$ 表示 $u\to n$ 的最短路（后者在反图上从 $n$ 出发即可）。

设 $\text{dp}[u][k]$ 表示从 $1$ 走到 $u$，已经走了 $f[u]+k$ 距离的路线数，显然只需要保留 $f[u]+g[u]+k\le f[n]+K$ 的状态。

对于原图中的一条边 $u\to v$，边权为 $w$，从 $(u,k)$ 走过去后，总路程变成了 $f[u]+k+w$。把它写成 $f[v]+k'$ 的形式，得到 $k'=k+f[u]+w-f[v]$。只要 $(v,k')$ 也被保留，就从 $(u,k)$ 向 $(v,k')$ 连边。这样我们就得到了一张分层图，在这张图上跑拓扑排序，同时做 DP 即可：

$$
\text{dp}[v][k']\leftarrow
\bigl(\text{dp}[v][k']+\text{dp}[u][k]\bigr)\bmod P
$$

就是判无穷，显然只需要看能否拓扑排序即可。如果拓扑排序能删掉所有保留的状态，答案就是 $\sum_{k=0}^{K}\text{dp}[n][k]$ 对 $P$ 取模。

单组时间复杂度 $O((n+m)\log n+(n+m)K)$，空间复杂度 $O(nK+m)$。

### 宝藏

> 给定一张 $n$ 个点、$m$ 条边的无向图，选定一个根和一棵生成树。根的深度为 $0$，父亲 $u$ 连向儿子 $v$ 的边产生 $w(u,v)\operatorname{dep}_v$ 的费用，求最小总费用。
>
> $1\le n\le 12$，$0\le m\le 10^3$，$1\le w\le 5\times 10^5$。可能有重边，取最小值即可。

直接分层状压 DP。设 $\text{dp}[i][S]$ 表示已经选了点集 $S$、树的最大深度不超过 $i$ 时的最小费用。枚举根 $r$，初始化 $\text{dp}[0][\{r\}]=0$。

预处理 $\text{dis}[S][v]=\min_{u\in S}w(u,v)$，即 $v$ 连向集合 $S$ 的**最短边**。枚举下一批加入的非空点集 $T\subseteq U\setminus S$，每个点各自选一条连向 $S$ 的边，转移为

$$
\text{dp}[i+1][S\cup T]\leftarrow
\min\left(\text{dp}[i+1][S\cup T],\ \text{dp}[i][S]+(i+1)\sum_{v\in T}\text{dis}[S][v]\right)
$$

这里允许从整个 $S$ 接边是因为：如果父亲实际比第 $i$ 层更浅，**统一乘 $i+1$ 只会多算费用**（多算了答案不优）；而任何最优树按真实深度逐层加入，都能恰好算出它的费用。

时间复杂度 $O(n3^n)$，空间复杂度 $O(n2^n)$。

### 列队

> 给定一个 $n\times m$ 的矩阵，初始 $a_{i,j}=(i-1)m+j$。每次取出 $(x,y)$ 的数，将这一行右侧的数左移，再将最后一列中下面的数上移，最后把取出的数放到 $(n,m)$。输出每次取出的数。
>
> $1\le n,m,q\le 3\times 10^5$。

把最后一列单拎出来，即 $n$ 个长为 $m-1$ 的行序列，以及一个长为 $n$ 的列序列。对于操作 $(x,y)$：

- 若 $y=m$，从列序列中删除第 $x$ 个数，输出并追加到列尾。
- 否则，从第 $x$ 行删除第 $y$ 个数作为答案，再从列序列中删除第 $x$ 个数，追加到这一行的末尾，最后把答案追加到列尾。

每个序列都只有“删除第 $k$ 个数”和“末尾追加”两种操作。给原始元素和后续追加的元素依次编号，用树状数组维护哪些位置还在，倍增查第 $k$ 个即可。但是每行都开一棵树状数组，空间显然不够。

注意一行中删掉哪个**位置**，只和这一行的操作有关，和实际编号无关。因此把所有 $y<m$ 的操作按行分组，离线逐行处理，用一个树状数组，记录每次删掉的位置 $\text{pos}[i]$ 即可。

再按时间顺序处理所有操作，用树状数组维护最后一列，每行只开一个 `vector` 记录历次追加的值。若 $\text{pos}[i]<m$，答案就是 $(x_i-1)m+\text{pos}[i]$；否则直接取 `row[x[i]][pos[i] - m]`。

时间复杂度 $O(n+m+q\log(n+m+q))$，空间复杂度 $O(n+m+q)$。

### 天天爱跑步

> 给定一棵 $n$ 个点的树，边长均为 $1$，每个点 $u$ 有一个观察时间 $w_u$。有 $m$ 个玩家，第 $i$ 个玩家在时刻 $0$ 从 $s_i$ 出发，每秒走一条边，沿简单路径走到 $t_i$ 后立即结束。
>
> 对每个点 $u$，求满足 $u\in \operatorname{path}(s_i,t_i)$ 且 $\operatorname{dist}(s_i,u)=w_u$ 的玩家数量。
>
> $1\le n,m\le 3\times 10^5$，$0\le w_u\le n$。

先把树定根在 $1$，记点 $u$ 的深度为 $\operatorname{dep}_u$。对于一条路径 $s\to t$，设 $p=\operatorname{lca}(s,t)$，拆成 $s\to p$ 和 $p\to t$ 两段分别考虑。为了不重复统计，我们把 $p$ 算在上行这一段，下行这一段不包含 $p$。

先看上行。玩家从 $s$ 走到点 $u$ 用了 $\operatorname{dep}_s-\operatorname{dep}_u$ 秒，因此被观察到的条件是

$$
\operatorname{dep}_s-\operatorname{dep}_u=w_u
\quad\Longleftrightarrow\quad
\operatorname{dep}_u+w_u=\operatorname{dep}_s
$$

移项之后，左边只和观察员有关，右边只和玩家有关。我们把上行路径按 $\operatorname{dep}_s$ 分类，点 $u$ 只需要查询 $\operatorname{dep}_u+w_u$ 这一类中，有多少条路径经过自己。

下行同理。玩家先从 $s$ 走到 $p$，再从 $p$ 走到 $u$，总共用了 $\operatorname{dep}_s+\operatorname{dep}_u-2\operatorname{dep}_p$ 秒，于是

$$
\operatorname{dep}_s+\operatorname{dep}_u-2\operatorname{dep}_p=w_u
\quad\Longleftrightarrow\quad
w_u-\operatorname{dep}_u=\operatorname{dep}_s-2\operatorname{dep}_p
$$

因此，下行路径按 $\operatorname{dep}_s-2\operatorname{dep}_p$ 分类，点 $u$ 查询 $w_u-\operatorname{dep}_u$ 这一类即可。

接下来直接用树上差分，统计每一类路径经过了哪些点。不过每个差分标记除了记录 $+1/-1$，还要带上它属于哪一类。

- 上行：在 $s$ 处给 $\operatorname{dep}_s$ 这一类加 $1$，在 $p$ 的父亲处给同一类减 $1$。若 $p$ 是根，则不用减。
- 下行：在 $t$ 处给 $\operatorname{dep}_s-2\operatorname{dep}_p$ 这一类加 $1$，在 $p$ 处给同一类减 $1$。若 $t=p$，这一段为空，直接跳过。

以上行为例，对于 $s\to p$ 上的任意一个点，它的子树里有 $s$ 处的 $+1$，但没有 $p$ 的父亲处的 $-1$，所以子树内的差分和为 $1$。再往 $p$ 上面走，两个标记就会同时落在子树里，相互抵消；其他分支的子树则两个都没有。下行也是一样，只是把减法放在 $p$，恰好让 $p$ 不被统计。

我们不需要给每个点都开一个桶。只开两个全局桶 $\text{cnt}_1,\text{cnt}_2$，分别存上行、下行的差分和，DFS 时先记下当前查询值，递归处理所有儿子，再把自己这里的差分标记加入桶中，最后用新的查询值减去进入时的查询值即可。

这里桶里的标记不用撤销。因为从进入 $u$ 到离开 $u$，新加入的恰好是 $u$ 子树内的标记；之前处理过的其他分支，在前后两次查询里都出现了，相减就没了。注意我们取的是桶中某一类的**净变化**，即使中间加入了负数标记，也不影响这个结论。

对应的统计部分就是：

```cpp
void dfs2(int u) {
    int x = dep[u] + w[u], y = w[u] - dep[u] + n;
    int before = cnt1[x] + cnt2[y];
    for (int v : g[u])
        if (v != fa[u][0]) dfs2(v);
    for (auto [key, val] : e1[u]) cnt1[key] += val;
    for (auto [key, val] : e2[u]) cnt2[key] += val;
    ans[u] = cnt1[x] + cnt2[y] - before;
}
```

其中 $\text{e}_1[u],\text{e}_2[u]$ 存放点 $u$ 上的两类差分标记。下行的分类值可能为负，所以存标记和查桶时统一加上 $n$。上行、下行都只需要开到 $2n$ 的桶。

倍增预处理 LCA，每条路径产生至多四个标记，最后一次 DFS 统计答案。时间复杂度 $O((n+m)\log n)$，空间复杂度 $O(n\log n+m)$。

### 愤怒的小鸟

> 给定第一象限内 $n$ 个互不相同的点，每次可以选一条形如 $y=ax^2+bx$ 且 $a<0$ 的抛物线，消灭这条抛物线经过的所有点。求消灭全部点所需的最少次数。
>
> 多测，$1\le n\le 18$，$0<x_i,y_i<10$，坐标均保留两位小数。

显然状压 DP，用 $\text{kill}[i][j]$ 表示经过第 $i,j$ 只猪的抛物线，能够消灭的小猪集合，容易数学推导计算；并设 $\text{dp}[S]$ 表示消灭集合 $S$ 中的小猪需要的最少小鸟数。

最直接的想法是枚举下一只鸟经过哪两只猪，不过每个状态这样要枚举 $O(n^2)$ 次。实际上，记全集为 $U=2^n-1$，取 $U\mathbin{\mathtt{xor}}S$ 的 lowbit 所对应的猪 $i$，固定下一只鸟经过它，只枚举另一只猪 $j$ 即可。转移为

$$
\text{dp}[S\cup\text{kill}[i][j]]
\leftarrow
\min\left(\text{dp}[S\cup\text{kill}[i][j]],\ \text{dp}[S]+1\right)
$$

这里也要枚举 $j=i$，对应单独消灭它。只要一条轨迹还经过其他猪，就能由 $i$ 和其中另一只猪确定，因此没有漏掉任何需要考虑的情况。对应的转移就是：

```cpp
for (int S = 0; S < all; ++S) {
    if (dp[S] == n + 1) continue;
    int i = __builtin_ctz(all ^ S);
    for (int j = 0; j < n; ++j) {
        if (!kill[i][j]) continue;
        int to = S | kill[i][j];
        dp[to] = min(dp[to], dp[S] + 1);
    }
}
```

总时间复杂度 $O(T(n^3+n2^n))$，空间复杂度 $O(n^2+2^n)$。
