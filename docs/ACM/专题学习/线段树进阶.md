## 势能线段树

这里主要涉及一些需要利用到势能分析的 trick。

### 平凡题（一句话题解）

- 区间整除，（区间加，可能有负数），区间求和
    - LOJ 6029，「雅礼集训 2017 Day1」市场，https://loj.ac/p/6029
    - 一个数最多被有效整除 $\log A$ 次，注意例如 $\lfloor \frac{-1}{2}\rfloor=-1$ 的情形。
    - 考虑区间加，每个节点维护 $\text{seg_min}$、$\text{seg_max}$，由于 $f(x)=x-\lfloor \frac{x}{k}\rfloor$ 单增，如果区间整除 $k$ 时 $\text{seg_min}$ 与 $\text{seg_max}$ 的 $\Delta$ 相同，那么该区间内的数整体都是变化 $\Delta$，直接打 add 的懒标记即可。
    - 势能分析考虑给每个节点 $\Phi(u)=\log(\max-\min+1)$，每暴力往下递归一次势能 $-1$。
- 区间开方，（区间加），区间求和
    - （无区间加）洛谷 P4145，上帝造题的七分钟 2，https://www.luogu.com.cn/problem/P4145
    - （有区间加）见后
    - 一个数最多被开方 $\log \log A$ 次就变为 $1$。
- 区间取模，区间求和
    - CF438D，The Child and Sequence，https://codeforces.com/problemset/problem/438/D
    - 一个数最多被有效取模 $\log A$ 次（分类讨论，若 $x\ge 2y$，则 $x\mod y<y\le \frac{x}{2}$；若 $y\le x<2y$，则 $x\mod y=x-y<\frac{x}{2}$）。

### LOJ 6507，「雅礼集训 2018 Day7」A

- 题目链接：https://loj.ac/p/6507

> 区间 and，区间 or，区间求 min（也可求 sum）
> 
> $1\le n,m\le 5\times 10^5$，$0\le A_i,x<2^{31}$，时间限制 2 s。

如果只是求 sum，每个 bit 都是相互独立的，也就可以从 0/1 序列入手，显然是一个区间覆盖问题；现在多了 min，位与位之间相关，就不得不**整体考虑**。我们给线段树的每个节点记录 $\text{seg_and}$、$\text{seg_or}$、$\text{seg_min}$ 三个信息，表示对应区间的所有元素的 and、or、min。

以 and 操作为例，如果 $(\text{seg_or}\  \text{and}\ x)=\text{seg_or}$，说明 $x$ 对该区间根本不起效，直接 return 即可；否则，区间内必有某些数的某几位会被置 0。

直接暴力递归下去的复杂度并不对（例如反复 `and 0` 再 `or INT_MAX`），不过我们可以修补一下，设计成：若 $(\text{seg_and}\ \text{and}\ x)=(\text{seg_or}\ \text{and}\ x)$，说明区间内所有数都变成了同一个值，直接打 cov 的懒标记即可，否则再暴力递归。

下面证明复杂度。我们设计序列的势能为 

$$
\Phi(A)=\sum\limits_{i=1}^{n-1} \text{popcount}(a_i \oplus a_{i+1})
$$

即**相邻元素对应位不同值的总和**。每次“有效”的区间 and/or 会拉齐相邻元素对应位的值，并可能会带来两端点处势能的抬升。单次操作势能最多抬升 $O(\log A)$，而势能每减小 1，需要遍历线段树上的 $O(\log n)$ 个区间（从根访问到叶子），因此时间复杂度为 $O((n+q)\log n\log A)$。
