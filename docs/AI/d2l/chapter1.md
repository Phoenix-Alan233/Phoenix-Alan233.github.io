??? 安装 d2l 的配置
    - 配置 conda 环境
        ```bash
        conda env remove d2l-zh
        conda create -n d2l-zh -y python=3.12 pip
        conda activate d2l-zh
        ```
    - 安装需要的包
        ```
        pip install -y jupyter d2l torch torchvision
        ```
    - 下载代码并启动 jupyter
        ```
        wget https://zh-v2.d2l.ai/d2l-zh.zip
        unzip d2l-zh.zip
        jupyter notebook
        ```
