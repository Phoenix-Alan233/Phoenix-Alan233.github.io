# Crypto（密码攻击）

## 现成轮子

- SageMath，开源数学软件系统
    - http://sagecell.sagemath.org，可供临时使用，但局限性很强（无法调其他包，代码长度有限制）
    - 更合理的方式是直接本地部署

- 单表替换
    - https://www.quipqiup.com，对自然语音文本的密文进行频率分析

- 质因数分解
    - https://factordb.com，很强大的质因子数据库
    - https://github.com/elliptic-shiho/primefac-fork，看上去挺牛逼的项目


## 有趣的网站

- [CryptoHack](https://cryptohack.org)，非常适合上手学密码学的平台
