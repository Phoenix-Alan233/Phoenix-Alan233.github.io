## CTF 概述

> 以下均默认竞赛模式为解题模式 Jeopardy。

### 方向

CTF 主要分为 **Misc**（安全杂项）、**Web**（网络攻防）、**Crypto**（密码攻击）、**Pwn**（漏洞利用）、**Reverse**（逆向工程）五大方向，偶尔也会有 **OSINT**（情报搜集）、**Stega**（隐写技术）、**PPC**（算法优化）、**Mobile**（移动安全）、**Blockchain**（区块链安全）等方向。
