    硬件设施⚓︎

    备注

    记录常见硬件的用途，以及看配置时容易混淆的参数。

    参考资料

    • 【硬核科普】从零开始认识主板
    • 【硬核科普】从零开始认识显卡

    一台电脑里有什么⚓︎

    硬件 主要负责什么
    CPU 执行指令，处理计算与程序中的各种判断
    GPU 图形渲染，以及适合并行的大量计算
    内存 暂存正在运行的程序和正在处理的数据
    SSD / HDD 长期保存系统、程序和文件
    主板 连接各个部件，提供插槽、接口和供电电路
    网卡、声卡 分别处理网络通信、音频输入输出
    电源、散热、机箱 供电、带走热量、固定和保护部件
    外设 键盘鼠标负责输入，显示器等负责输出

    以打开一个程序为例：系统把需要的代码和数据从硬盘读入内存，CPU 执行指令，图形工作交给 GPU，最后显示器呈现画面。保存文件时，数据再写回硬盘。

    笔记本、迷你主机也有这些部件，只是集成度更高，很多东西直接焊在主板上。

    CPU：中央处理器⚓︎

    CPU 负责取指令、执行计算和控制程序流程。内部有运算单元、控制逻辑、寄存器和缓存；寄存器保存当前计算直接使用的少量数据。

    • 核心（Core）：实际执行工作的硬件单元。多核心有利于同时运行多个任务，也能加速可以拆分的计算。
    • 线程（Thread）：配置表里的线程数通常指硬件线程数，也就是系统看到的逻辑处理器数量。SMT（Intel 的一种实现叫超线程）让一个核心同时容纳多个线程，但这些线程共享核心资源。因此，8 核 16 线程仍然只有 8 个物理核心。
    • 频率：如 4 GHz，表示每秒约 40 亿个时钟周期。一个周期能完成多少工作还取决于架构、指令和访存，跨架构比较时只看 GHz 很容易误判。
    • 睿频 / Boost：在温度、功耗等条件允许时自动提高频率。标称最高频率通常不代表所有核心都能长期跑到这个数值。

    串行程序更看重单核性能，并行编译、渲染等任务还会受益于更多核心；具体能快多少，要看程序能并行的部分有多少。Intel 的 CPU 参数说明也区分了核心数、频率与实际工作负载。

    缓存与指令集⚓︎

    Cache 是 CPU 附近的小容量高速存储，用来减少访问内存的次数。常见的 L1、L2、L3 缓存，通常越靠前越小、越快；具体哪些由核心独享、哪些共享，要看架构。

    从寄存器、Cache、内存到 SSD / HDD，通常容量逐渐增大、访问延迟逐渐升高。这也是程序里“尽量连续访问内存”“提高缓存命中率”有意义的原因。

    指令集规定 CPU 能执行哪些指令，常见的有 x86-64、ARM64。某个架构的机器码通常不能直接在另一个架构上运行，需要重新编译或通过转译、模拟执行。

    另外，SoC（片上系统）会把 CPU、GPU、内存控制器等集成到一颗芯片中；其中的 NPU 是面向神经网络计算的专用单元，常用于低功耗 AI 推理。

    GPU：图形处理器与显卡⚓︎

    GPU 擅长同时处理大量相似的计算，比如图形渲染、矩阵运算。程序需要通过相应的软件接口使用 GPU；普通代码不会因为装了显卡就自动加速。NVIDIA 的介绍对此有更详细的说明。

    GPU 是处理芯片，显卡还包括显存、供电和散热等部件。 核显集成在处理器或 SoC 中，通常共享系统内存；独显有独立的 GPU 和显存，但笔记本里的独显也可能直接焊在主板上。

    看显卡主要看三件事：

    • 计算能力：影响渲染、训练等计算速度。TFLOPS 表示每秒万亿次浮点运算，但比较时必须看计算精度、是否使用稀疏计算等条件；GPU 的“核心数”也不能直接和 CPU 核心数比较。
    • 显存容量：决定能容纳多少纹理、模型和中间数据。显存不足时，程序可能报错，或需要分批处理、把部分数据移到内存。
    • 显存带宽：决定 GPU 每秒能从显存搬多少数据。容量和带宽是两回事；GDDR 是常见的显存类型，HBM 则通过堆叠存储芯片提供高带宽。

    显存与系统内存在独显系统中通常分开，来回传数据也有成本。做计算时还要看驱动和软件支持，例如 CUDA 面向 NVIDIA GPU，相关编程另见 CUDA 笔记。

    内存：RAM⚓︎

    日常说的内存一般指 DRAM，保存程序运行期间的数据，断电后内容丢失。容量不足时，系统可能把部分数据换出到硬盘上的交换空间，再次访问就会慢很多。

    • 容量：例如 16 GB、32 GB。决定能同时容纳多少程序和数据；容量已经够用时，继续加内存未必让计算更快。
    • 代际与规格：DDR4、DDR5 是不同代际，不能直接混插。台式机常见 DIMM，笔记本常见 SO-DIMM 或板载内存；LPDDR 偏重低功耗，能否更换取决于具体设计。
    • 传输速率：DDR5-6000 的 6000 指 6000 MT/s，即每秒 60 亿次数据传输。DDR 每个时钟周期传两次，对应的时钟频率是 3000 MHz。
    • 时序：CL 等数字描述等待的时钟周期数，实际延迟还要结合频率看，不能只比较 CL 大小。
    • 通道：多个内存通道可以同时传数据，提高带宽。双通道要按主板说明书插在对应位置；插两条、四条内存分别能组成什么通道配置，由平台决定。

    DDR5 单条内存内部有两个子通道，与平台上插两条内存启用双通道是不同层次的概念。ECC 内存提供错误检测与纠正能力，需要 CPU、主板和内存共同支持；DDR5 自带的 On-die ECC 只负责芯片内部的纠错，系统级 ECC 还要覆盖传输等环节。Kingston 的 DDR5 说明介绍了这些区别。

    XMP / EXPO 是预设的内存超频配置。标称速度能否稳定达到，仍取决于内存控制器、主板和插条数量。

    存储：SSD、HDD 与移动存储⚓︎

    硬盘用于保存断电后仍要保留的数据，主要有两类：

    类型 原理与特点
    HDD：机械硬盘 磁头读写旋转盘片。适合大容量存储，有寻道延迟、噪声，工作时怕碰撞
    SSD：固态硬盘 主控管理 NAND 闪存，没有机械寻道，随机访问通常快得多

    SSD 的 TLC、QLC 分别表示每个存储单元存 3、4 bit。单元存得越多，控制和纠错越复杂；具体性能还取决于主控、缓存、容量和固件，不能只凭颗粒类型下结论。

    M.2、SATA、PCIe、NVMe⚓︎

    这些名词描述的层次不同：

    名词 指什么
    2.5 英寸、3.5 英寸 硬盘的外形规格
    M.2 模块的外形与连接器规格，也能用于无线网卡等设备
    SATA 常见存储接口，可连接机械硬盘或固态硬盘
    PCIe 高速扩展总线，显卡、网卡、SSD 都可以使用
    NVMe 面向非易失性存储的通信协议，本机 NVMe SSD 通常通过 PCIe 连接

    例如 “M.2 2280、PCIe 4.0 ×4、NVMe SSD”：2280 表示宽 22 mm、长 80 mm，PCIe 4.0 ×4 表示使用 4 条第四代 PCIe 通道，NVMe 是通信协议。

    所以，M.2 SSD 可能走 SATA，也可能走 PCIe；安装时还要确认插槽支持的协议、长度和缺口规格。参见 Kingston 对两类 M.2 SSD 的说明。

    速度和寿命怎么看⚓︎

    • 顺序读写：连续搬运大文件的速度，常用 MB/s、GB/s 表示。
    • 随机读写与延迟：访问分散小块数据的能力。IOPS 表示每秒完成多少次 I/O，比较时要看块大小和队列深度；日常响应也很受低队列深度下的延迟影响。
    • 缓存与持续写入：部分 SSD 用 SLC 缓存提高短时间写入速度，缓存耗尽后可能明显降速。
    • TBW：额定累计写入量，常用于描述耐久度和保修条件；实际故障可能早于或晚于这个数值。

    U 盘、SD / microSD 卡也使用闪存，通过 USB、读卡器等连接。移动硬盘则是在 HDD 或 SSD 外面加上外壳和接口转换电路，速度同时受内部硬盘、接口和线材影响。光驱读写 CD、DVD、蓝光等光盘，常见用途是读取旧资料。

    NAS 是通过网络提供文件存储的设备，本质上也是一台电脑。RAID 把多块盘组织在一起，有些级别侧重性能，有些提供冗余；RAID 0 没有冗余，其他级别的冗余也不能挽回误删，重要数据仍需要独立备份。

    容量单位也容易混淆：厂商常用十进制，1 GB = 10⁹ B；1 GiB = 2³⁰ B。因此 1 TB 大约是 931 GiB，这是计量方式的区别。

    主板：把各个部件连起来⚓︎

    主板上的导线、插槽和控制芯片负责让各个部件通信。内存通常直接连接 CPU 的内存控制器，部分 PCIe 设备直连 CPU，其他接口则经过芯片组。

    • CPU 插座与支持列表：安装 CPU 要同时看插座、芯片组与 BIOS 支持，插座相同也未必兼容。
    • 板型：常见 ATX、Micro-ATX（mATX）、Mini-ITX，通常依次更小。它们主要影响尺寸和扩展空间，还要与机箱匹配。
    • VRM（供电电路）：把电源提供的电压转换成 CPU 等芯片需要的低电压，供电能力和温度会影响持续高负载运行。
    • 扩展能力：看内存插槽、PCIe 插槽、M.2 插槽、SATA 和 USB 接口，以及是否板载网卡、声卡。

    PCIe 通道⚓︎

    PCIe 的 代际决定每条通道的传输能力，×1、×4、×8、×16 表示通道数量。不同代际通常可以兼容，实际链路按双方共同支持的代际和通道数运行。

    插槽长度和实际接线数也可能不同：一个外形为 ×16 的插槽，可能只接了 ×4。部分 M.2、SATA 或 PCIe 插槽还会共享资源，插入一个设备可能影响另一个接口；经过芯片组的设备还共享芯片组到 CPU 的带宽。具体以主板说明书为准。Intel 的 PCIe 说明区分了 CPU 直连与芯片组通道。

    BIOS / UEFI⚓︎

    BIOS / UEFI 是保存在板载闪存中的固件，开机时初始化硬件，再启动操作系统。平时说“进 BIOS”，通常就是进入固件设置界面，可以调整启动顺序、风扇曲线和内存参数。

    主板上的纽扣电池主要维持实时时钟，部分平台也靠它保存设置；固件本身保存在闪存中。TPM 则提供密钥保护等安全功能，可以是独立芯片，也可以由平台固件实现。

    电源、散热与机箱⚓︎

    电源与电池⚓︎

    台式机的 PSU 把交流电转换成各部件需要的直流电；笔记本通常由外部适配器供电，并配有电池。

    • 额定功率表示电源能提供的输出能力。750 W 电源不会一直消耗 750 W，实际耗电随负载变化，还要计入转换损耗。
    • 转换效率表示输出功率占输入功率的比例。例如输出 400 W、效率 90%，插座侧约消耗 444 W，差额主要变成热量。
    • 80 PLUS 金牌等认证主要描述规定条件下的效率。供电稳定性、保护电路和噪声仍要另外看。Corsair 的效率说明解释了输入、输出与损耗的关系。
    • 模组电源允许拆卸部分或全部线材，方便布线；更换电源时要按新电源的兼容要求配线，电源端针脚定义可能不同。

    电源还要匹配机箱尺寸（如 ATX、SFX）和 CPU、显卡需要的供电接口，并为负载波动留出余量。CPU 标称的 TDP 用于描述特定条件下的热设计要求，实际峰值功耗要另看功耗限制。

    电池容量常用 Wh，功率用 W。粗略地说，60 Wh 电池在整机平均消耗 15 W 时可工作约 4 小时，实际还受损耗、电池老化和使用负载影响。UPS 则在停电时为台式机、NAS 等提供短时间供电。

    散热与机箱⚓︎

    散热的过程是把芯片的热量传给散热器，再排到机箱外：

    • 风冷：通过底座、热管或均热板把热量传到鳍片，再由风扇带走。
    • 水冷：通过水泵和冷却液把热量搬到冷排，最终仍由风扇散到空气中。
    • 硅脂 / 导热垫：填补接触面间的空隙，改善热传导。

    温度或功耗达到限制时，CPU、GPU 会降低频率，实际性能也会下降。因此同一款芯片装在不同机器里，持续性能可能不同。

    机箱要容纳主板、电源、显卡和散热器，关注显卡长度与厚度、风冷高度、冷排位置和进出风空间。风扇负责推动空气，防尘网和内部布线也会影响风道。

    接口、线材与扩展坞⚓︎

    接口外形、传输协议、供电能力要分别看。 两个接口长得一样，支持的功能也可能不同。

    接口 / 设备 常见用途 需要分清什么
    USB-A、USB-C 键鼠、存储、手机等外设 A / C 描述连接器外形，速度要看 USB 协议
    USB PD 通过 USB 协商供电 可用功率由供电端、设备和线材共同决定
    Thunderbolt（雷电） 扩展坞、高速存储、外接显示器等 雷电 3 及之后使用 USB-C 外形，要确认双方支持的版本和功能
    HDMI、DisplayPort（DP） 传输数字视频和音频 可用分辨率、刷新率、色深受两端设备与线材共同限制
    RJ45 网口 连接双绞线以太网 端口速率、网线质量和对端设备共同影响连接
    3.5 mm 音频口 耳机、音箱、麦克风 耳机、麦克风可能分口，也可能合用一个插孔
    USB Hub、扩展坞 把一个接口扩展成多个 多个设备可能共享上行带宽，部分扩展坞需要独立供电

    例如，一个 USB-C 口可能支持高速数据、视频和充电，也可能只支持其中部分功能。线材同样有区别：支持大功率充电的线，数据传输速度未必高。USB-IF 的说明明确区分了连接器与可选功能。

    网络设备⚓︎

    网卡（NIC）负责让电脑接入网络，可以板载，也可以通过 PCIe、M.2、USB 等方式连接。有线网卡连接以太网，无线网卡连接 Wi-Fi；蓝牙则常用于耳机、键鼠等近距离外设。

    家里常见的网络设备可以这样区分：

    设备 主要用途
    光猫（ONT） 接入运营商的光纤网络
    路由器 在不同网络之间转发数据；家用设备通常还负责 NAT、DHCP 等
    交换机 连接同一局域网内的多台有线设备
    无线接入点（AP） 让无线设备通过 Wi-Fi 接入局域网

    家用“无线路由器”通常把路由器、交换机和 AP 合在一起，光猫也可能集成部分功能。设备角色可参考 Cisco 的网络基础介绍。

    网速常用 bit/s，文件传输常用 B/s，1 B = 8 bit。因此 1 Gbit/s 理论上对应 125 MB/s，扣除协议开销后还会更低。带宽描述每秒能传多少数据，延迟描述一次通信要等多久；下载快和游戏延迟低是两个指标。

    Wi-Fi 的实际速度还受距离、墙体、干扰和同时使用的设备影响。路由器宣传的多个频段总速率，也不能直接当成单台电脑的下载速度。

    显示器与其他外设⚓︎

    显示器⚓︎

    • 尺寸与分辨率：尺寸通常指屏幕对角线长度；分辨率是像素数量，例如 1920 × 1080。同样尺寸下，分辨率更高通常更细腻，但也可能需要系统缩放。
    • 刷新率与帧率：144 Hz 表示屏幕每秒可刷新 144 次，FPS 表示程序每秒生成多少帧，二者要分开看。
    • 响应时间与输入延迟：前者主要描述像素变色速度，后者描述输入操作到画面反馈的延迟。宣传的“1 ms”不能直接当成整套系统的延迟。
    • 面板：IPS、VA、TN 属于 LCD，需要背光；OLED 像素自发光。Mini-LED 通常指 LCD 的背光技术。
    • 色彩与亮度：色域描述能显示的颜色范围，色准描述颜色是否准确。HDR 效果还依赖亮度、对比度、局部调光能力和片源。

    显示器最终能以什么模式工作，要同时看 GPU 输出、接口、线材和显示器支持的组合。

    输入、音频与其他设备⚓︎

    硬件 用途与常见参数
    键盘、鼠标、触控板 输入文字、按键和指针操作。鼠标 DPI 影响移动灵敏度，回报率影响上报频率，二者都不等于实际精度
    手柄、数位板、触摸屏 分别提供按键摇杆、笔输入、触摸输入；数位板还涉及压感和倾斜识别
    声卡 / 音频接口 DAC 把数字音频转成模拟输出，ADC 把麦克风等模拟输入转成数字数据；可以板载或外接
    耳机、音箱、麦克风 负责声音播放与采集。USB 耳机、USB 麦克风通常已集成所需的音频电路
    摄像头 采集视频，关注分辨率、帧率、对焦和弱光表现
    采集卡 把相机、游戏机等设备的视频信号送入电脑，用于录制或直播；采集规格与直通规格可能不同
    打印机、扫描仪 分别把电子内容输出到纸张、把纸面内容转成数字文件

    在 Linux 下查看硬件⚓︎

    lscpu                                      # CPU 架构、核心、线程与缓存
free -h                                    # 内存总量及当前使用情况
lsblk -o NAME,MODEL,SIZE,TYPE,TRAN           # 硬盘型号、容量及连接方式
lspci                                      # PCIe 等 PCI 设备，如显卡、网卡
lsusb                                      # USB 设备
nvidia-smi                                 # NVIDIA GPU、显存与使用状态

    nvidia-smi 需要 NVIDIA 驱动及相应工具；部分系统还需安装 pciutils、usbutils 才能使用 lspci、lsusb。查出来的型号用于确认设备，实际速度和瓶颈还要结合运行时负载看。
